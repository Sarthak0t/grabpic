# GrabPic

AI-powered event media discovery platform.

## Problem

Large events generate thousands of photographs from multiple photographers and devices. Attendees often struggle to find the photographs they appear in.

## Solution

GrabPic allows attendees to discover event photographs containing them by submitting a selfie and using face-embedding based similarity search.
